Specs and completion reports are stored here with numbered prefixes.

## Naming
- `001-feature-name.md` - Spec
- `001-feature-name-complete.md` - Completion report

## Spec Structure
- **Problem**: What needs to be solved
- **Requirements**: What must be true when done
- **Approach** (optional): High-level implementation notes

## Completion Reports
Written when a spec is implemented. Documents what was actually built and any deviations from the spec.
